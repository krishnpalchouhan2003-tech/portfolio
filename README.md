# Krishnpal Chouhan — Portfolio

Personal portfolio of a frontend engineer building casino and sportsbook products, themed like one.

- Scroll-driven sections: a flipping playing card, live odds ticker, slot-machine skills, roulette-wheel experience
- Playable demo games (Crash, Plinko, Mines) with demo chips only — no real money
- Tuned for phones: GPU-friendly animations, haptics, tilt-to-shine card

**Stack:** React 19, Vite, Tailwind CSS v4, Motion, Lenis

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # game math checks
npm run build    # production build in dist/
```

All content (profile, projects, experience, skills) lives in `src/data.js`.
